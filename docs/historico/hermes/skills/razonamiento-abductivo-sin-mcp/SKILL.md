# Razonamiento abductivo (sin herramientas de motor)

> Variante de control de la prueba A/B (EXP-017). Tiene el **mismo método** que la skill con el MCP abd-mind, pero cada paso se hace a mano, por escrito, en tu razonamiento. No tienes un motor que lleve el caso: llévalo tú.

## Cuándo usarlo

- Dos o más fuentes (analistas, sensores, testigos, informes) dicen cosas que parecen incompatibles.
- El usuario pide la causa de un conjunto de hechos que no encajan.
- Llega evidencia nueva sobre un caso que ya analizaste.

## Flujo

1. **Escribe el caso:** una descripción breve. Si la pregunta tiene alternativas ("¿estructural o transitoria?", "¿A o B?"), escribe esas alternativas, incluida una mixta si cabe.
2. **Por cada fuente, anota quién observa y desde qué marco** (metodología, perspectiva, instrumento). Separa lo que el usuario quiere entender (el explanandum) de la evidencia que reúnes para decidir.
3. **Busca evidencia para cada alternativa**, no solo para la que parece obvia: antes de evaluar, intenta encontrar hechos que favorecerían a cada una.
4. **Separa hechos de opiniones.** Las opiniones ("comprar", "vender") no son evidencia.
5. **Escribe tus hipótesis antes de decidir.** Cada una responde la pregunta y trae predicciones con horizonte: qué debería observarse si es cierta. Incluye al menos una que postule algo no observado si los hechos no encajan con lo conocido.
6. **Genera más hipótesis rivales,** también las que no se te ocurrirían primero.
7. **Contrasta cada hipótesis con cada hecho:** ¿lo explica, le es indiferente o lo contradice? Si ninguna explica los hechos importantes, propone una hipótesis nueva que sí los explique.
8. **Elige la mejor explicación.** Si dos o más quedan muy parecidas, o la elección depende de un solo juicio dudoso, identifica **qué observación las separaría**: qué predice cada una distinto. Busca esa observación antes de concluir, o preséntala al usuario.
9. Si una hipótesis predice algo con horizonte, ofrece revisar en esa fecha.
10. Ante evidencia nueva, vuelve a contrastar todas las hipótesis, incluidas las que habías descartado.

## Reglas estrictas

- **No promedies** posiciones de los observadores ni presentes una postura intermedia como explicación.
- Si ninguna explicación es suficiente, dilo claramente y di qué faltaría. No elijas "la menos mala".
- Si tu respuesta depende de un solo juicio dudoso, dilo. No la presentes como conclusión firme.
- La respuesta explica lo ocurrido; **no es una recomendación de inversión ni de acción**. Si el usuario pregunta qué hacer, separa ambas cosas.

## Cómo responder (Telegram)

Mensaje corto con cinco partes:

- la respuesta a la pregunta;
- la explicación ganadora;
- qué postula que no está confirmado;
- la alternativa principal;
- qué vigilar para cambiar de opinión.
